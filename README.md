# Fruit Burst 🍉🍊🥭

## Description

**Fruit Burst** is a responsive e-commerce landing page built using **Tailwind CSS** and **DaisyUI**.  
It showcases fruits, deals, banners, and a team section with a **CSS-only typewriter animation**.

**Key Focus:**

- Pixel-perfect design based on Figma mockups.

## Features ✨

- Fully responsive layout using Tailwind CSS.
- DaisyUI components for cards, modals, and buttons.
- Product showcase with ratings and modals.
- Hero carousel with navigation arrows.
- Countdown timer for deals.
- Team section highlighting staff members.
- Hover effects and smooth transitions throughout.
